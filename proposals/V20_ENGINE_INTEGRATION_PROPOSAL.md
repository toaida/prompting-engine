## DEFAULT V20 RUNTIME ORDER

```
1. Photo existence reason
2. Camera relationship
3. Attention routing path
4. Environment + HK locality
5. Body language with action justification
6. Object logic / staged authenticity
7. Lighting / night realism if needed
8. Film / media format / carousel logic from V19
9. Anti-AI check
```

This order prevents common failures:
- attractive subject with no reason to be photographed
- body pose with no physical/action logic
- objects as props rather than evidence
- generic Asian city instead of HK
- night scenes with no light-source behavior
- direct camera gaze where public context makes it implausible
